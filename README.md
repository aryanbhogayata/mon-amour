# For My Mon Amour — Personalized GitHub Pages Website

This version has been personalized with uploaded photos of Aryan and Kalpana.

## Included
- Real photos placed into the birthday, scrapbook, and finale sections
- 11 monthly memory cards
- Personalized love letter and reasons
- Vintage romantic single-page website

## Important notes
- No actual video files were found in the uploaded ZIP. Only image and screenshot files were available, so the video-call moments were used as scrapbook memories instead.
- The supplied MP3 is bundled at `assets/music/blue.mp3` and already configured. Only publish it if you have the necessary rights. No code changes are needed. Opening the envelope starts the audio; the sticky Our song button provides controls. If there is no file, use the official YouTube player or choose a private audio file on your own device. YouTube requires HTTP(S) hosting, and playback can still be restricted by YouTube or the browser.
- To preview with hosting locally, run `python -m http.server 8000` from the extracted folder, then open `http://localhost:8000`.

## GitHub Pages deploy
1. Upload all files to a GitHub repository.
2. Enable **Settings → Pages**.
3. Deploy from the `main` branch and `/ (root)`.


- The dates under the 11 memory photos have been removed, per request.

## Privacy
GitHub Pages can expose the photos, messages and audio publicly. The robots metadata is not password protection. Confirm consent and music publishing rights before uploading.
